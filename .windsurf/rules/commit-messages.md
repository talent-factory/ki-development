## Message-Format

```
type: Kurze Beschreibung

Detaillierte Erklärung
- Änderung 1
- Änderung 2
```


### Commit-Types

- `feat:` - Neue Features
- `fix:` - Bugfixes
- `docs:` - Dokumentationsänderungen
- `chore:` - Wartungsarbeiten
- `refactor:` - Code-Refactoring
- `test:` - Test-Änderungen
