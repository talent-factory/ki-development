* Sie können die erstellten Embeddings praktisch für Ähnlichkeitsberechnungen nutzen

In dieser Übung kombinieren Sie die Konzepte aus den Kapiteln zu Vector Stores und Embeddings, um ein praktisches semantisches Suchsystem zu implementieren. Sie werden mit vortrainierten Embeddings arbeiten, diese in einem Vector Store organisieren und anschließend ähnliche Dokumente finden.
