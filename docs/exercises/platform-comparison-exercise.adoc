=== Aufgabe: Vergleich von AI-Plattformen
:imagesdir: ../images/

==== Lernziele
* Sie können verschiedene AI-Plattformen praktisch vergleichen
* Sie verstehen die Stärken und Schwächen verschiedener Ansätze
* Sie können eine fundierte Plattform-Auswahl für ein Projekt treffen

==== Aufgabenstellung

**Teil 1: Praktischer Test (60 Minuten)**

Testen Sie mindestens **zwei** der folgenden Plattformen:

1. **Flowise AI** (bereits behandelt)
2. **Langflow** 
3. **n8n** (https://n8n.io/)
4. **Make AI** (https://make.com/) - kostenlose Testversion

**Für jede Plattform:**
1. Registrieren Sie sich (kostenlose Version)
2. Erstellen Sie einen einfachen AI-Workflow:
   - Text-zu-Text Transformation (z.B. Zusammenfassung)
   - Oder: Einfacher Chatbot
   - Oder: Text-Klassifikation

**Teil 3: Empfehlung (15 Minuten)**

Schreiben Sie eine kurze Empfehlung (200-300 Wörter):

1. **Für Anfänger ohne Programmiererfahrung**: Welche Plattform empfehlen Sie?
2. **Für fortgeschrittene Nutzer**: Welche Plattform bietet die beste Flexibilität?
3. **Für Unternehmen**: Welche Plattform eignet sich am besten für professionelle Projekte?

Begründen Sie Ihre Empfehlungen basierend auf Ihren praktischen Erfahrungen.

==== Zusatzaufgabe (Optional)

**Erstellen Sie einen komplexeren Workflow:**
- Kombinieren Sie mehrere AI-Services (z.B. Text-Generierung + Sentiment-Analyse)
- Integrieren Sie externe APIs oder Datenquellen
- Dokumentieren Sie Herausforderungen und Lösungsansätze
