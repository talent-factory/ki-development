## 🏃‍♂️ Lokale Installation

### Voraussetzungen

- Python 3.8+
- Git
- OpenAI oder Anthropic API-Schlüssel

### Setup

1. **Repository klonen:**
```bash
git clone https://github.com/IHR-USERNAME/ai-course-assistant.git
cd ai-course-assistant
```

2. **Abhängigkeiten installieren:**
```bash
pip install -r requirements.txt
```

3. **Umgebungsvariablen konfigurieren:**
```bash
# .env Datei erstellen
echo "OPENAI_API_KEY=ihr-api-schluessel" > .env
# ODER
echo "ANTHROPIC_API_KEY=ihr-api-schluessel" > .env
```

4. **App starten:**
```bash
streamlit run app.py
```

5. **Browser öffnen:** http://localhost:8501

## 🌐 Deployment

Die App ist automatisch auf Streamlit Cloud deployed. Bei Änderungen:

1. **Code committen:**

2. **Streamlit Cloud** deployed automatisch die neueste Version
