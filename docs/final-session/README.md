# 🎯 Finaler Kursabend: AI-CLI Tools & Workflow Automation

**Datum:** 25.11.2025 (6. Kursabend)  
**Dauer:** 4 x 50 Minuten (18:00 - 21:50)  
**Teilnehmende:** 3 Personen  
**Fokus:** Praktische AI-CLI Tools, Slash Commands, Abschlussprojekt

## 📚 Pädagogische Struktur

### 🎯 **Lernziele des Abends**
- **Praktisch:** Installation und Nutzung moderner AI-CLI Tools
- **Konzeptionell:** Verstehen von AI-Workflow-Automation
- **Kreativ:** Entwicklung eigener Slash Commands
- **Reflektiv:** Kursrückblick und Zukunftsplanung

### 🔄 **Didaktisches Konzept**
```
Theorie (20%) → Demonstration (30%) → Hands-On (40%) → Reflexion (10%)
```

### 📋 **Lektionsübersicht**

| Zeit | Lektion | Schwerpunkt | Methode |
|------|---------|-------------|---------|
| 18:00-18:50 | **L1: CLI-Setup** | Installation & Grundlagen | Demo + Hands-On |
| 19:00-19:50 | **L2: Tools in Aktion** | Praktische Anwendung | Live-Coding |
| 20:00-20:50 | **L3: Neue Trends** | Aktuelle Entwicklungen | Exploration |

## 🎓 **Pädagogische Best Practices**

### ✅ **Aktivierung Vorwissen**
- Kurzer Rückblick auf RAG-Abend
- Verbindung zu bereits gelernten Konzepten
- Motivation durch praktische Relevanz

### ✅ **Progressiver Schwierigkeitsgrad**
1. **Einfach:** CLI-Installation (geführt)
2. **Mittel:** Tool-Anwendung (semi-geführt)
3. **Komplex:** Trend-Analyse (explorativ)
4. **Kreativ:** Eigene Commands (selbstständig)

### ✅ **Multimodale Lernansätze**
- **Visuell:** Demos, Screenshots, Diagramme
- **Auditiv:** Erklärungen, Diskussionen
- **Kinästhetisch:** Hands-On Übungen, Coding
- **Sozial:** Peer-Learning, Gruppenaustausch

### ✅ **Kontinuierliche Erfolgserlebnisse**
- Jede Lektion hat messbare Outputs
- Sofortige Funktionalitätstests
- Positive Verstärkung bei Erfolgen
- Konstruktive Hilfe bei Problemen
