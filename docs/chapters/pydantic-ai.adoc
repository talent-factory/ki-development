PydanticAI ist eine leistungsstarke Bibliothek, die die Stärken von Pydantic mit modernen KI-Modellen verbindet. Sie ermöglicht es Entwicklern, strukturierte Daten aus LLM-Antworten (Large Language Models) zu extrahieren und zu validieren. In diesem Leitfaden werden wir die Grundlagen von PydanticAI kennenlernen und praktische Anwendungsfälle erkunden.

== Überblick über PydanticAI

=== Was ist PydanticAI?

PydanticAI ist eine Erweiterung der beliebten Pydantic-Bibliothek, die speziell für die Arbeit mit KI-Modellen entwickelt wurde. Während Pydantic für die Datenvalidierung und -serialisierung in Python bekannt ist, fügt PydanticAI Funktionen hinzu, die es ermöglichen, strukturierte Daten direkt aus den Antworten von Sprachmodellen zu extrahieren.

Die Hauptvorteile von PydanticAI sind:

* *Typsicherheit*: Definiere genau, welche Datenstrukturen du von KI-Modellen erwartest
* *Validierung*: Automatische Überprüfung, ob die Antworten den erwarteten Formaten entsprechen
* *Einfache Integration*: Nahtlose Zusammenarbeit mit beliebten KI-Bibliotheken wie LangChain
* *Fehlerbehandlung*: Robuste Mechanismen zum Umgang mit unerwarteten Antwortformaten

=== Anwendungsfälle

PydanticAI eignet sich besonders für folgende Szenarien:

* Extraktion strukturierter Informationen aus Texten
* Konvertierung von natürlicher Sprache in strukturierte Daten
* Validierung von KI-generierten Antworten
* Erstellung von Schnittstellen zwischen KI-Modellen und Datenbanken oder APIs

[source,python]
----
# Einfaches Beispiel für PydanticAI
from pydantic import BaseModel, Field
from pydantic_ai import PydanticAI

# Definiere ein Datenmodell
class Person(BaseModel):
    name: str
    alter: int
    beruf: str = Field(description="Die berufliche Tätigkeit der Person")

# Verwende PydanticAI, um Informationen zu extrahieren
text = "Max Mustermann ist ein 42-jähriger Softwareentwickler aus Berlin."
person = PydanticAI().run(Person, text)

print(person)  # Person(name='Max Mustermann', alter=42, beruf='Softwareentwickler')
----

== Fragen an Chat-Modelle stellen

=== Grundlegende Konzepte

Um Fragen an Chat-Modelle zu stellen und strukturierte Antworten zu erhalten, kombinieren wir PydanticAI mit LLM-Bibliotheken wie OpenAI oder LangChain. Der grundlegende Ablauf ist wie folgt:

1. Definiere ein Pydantic-Modell für die erwartete Antwortstruktur
2. Stelle eine Frage an das Sprachmodell
3. Verwende PydanticAI, um die Antwort in die definierte Struktur zu konvertieren

[source,python]
----
from pydantic import BaseModel, Field
from pydantic_ai import PydanticAI
from langchain_openai import ChatOpenAI

# Definiere ein Modell für die Antwort
class Wettervorhersage(BaseModel):
    temperatur: float = Field(description="Temperatur in Grad Celsius")
    niederschlag: bool = Field(description="Ob Niederschlag erwartet wird")
    beschreibung: str = Field(description="Kurze Beschreibung des Wetters")

# Initialisiere das Sprachmodell
llm = ChatOpenAI(model_name="gpt-3.5-turbo")

# Stelle eine Frage und extrahiere strukturierte Daten
frage = "Wie wird das Wetter morgen in Zürich sein?"
vorhersage = PydanticAI(llm=llm).run(Wettervorhersage, frage)

print(f"Temperatur: {vorhersage.temperatur}°C")
print(f"Niederschlag: {'Ja' if vorhersage.niederschlag else 'Nein'}")
print(f"Beschreibung: {vorhersage.beschreibung}")
----

=== Fortgeschrittene Techniken

Du kannst die Genauigkeit der extrahierten Daten verbessern, indem du:

* Detaillierte Beschreibungen für jedes Feld hinzufügst
* Validatoren für Felder definierst
* Beispiele für die erwarteten Werte bereitstellst

[source,python]
----
from pydantic import BaseModel, Field, validator
from typing import List

class Rezept(BaseModel):
    name: str = Field(description="Der Name des Gerichts")
    zutaten: List[str] = Field(description="Liste der benötigten Zutaten")
    zubereitungszeit: int = Field(description="Zubereitungszeit in Minuten")
    schwierigkeitsgrad: str = Field(description="Schwierigkeitsgrad: einfach, mittel oder schwer")
    
    @validator('schwierigkeitsgrad')
    def validate_schwierigkeitsgrad(cls, v):
        allowed = ["einfach", "mittel", "schwer"]
        if v.lower() not in allowed:
            raise ValueError(f"Schwierigkeitsgrad muss einer der folgenden sein: {', '.join(allowed)}")
        return v.lower()
----

==== Übung: Nachrichtenanalyse

Entwickle ein Pydantic-Modell für die Analyse einer Nachricht, das folgende Informationen extrahiert:
- Stimmung (positiv, neutral, negativ)
- Hauptthema
- Dringlichkeit (1-5)
- Liste der erwähnten Personen

Verwende dann PydanticAI, um diese Informationen aus einer Beispielnachricht zu extrahieren.

*Lösung:*

[source,python]
----
from pydantic import BaseModel, Field, validator
from typing import List
from pydantic_ai import PydanticAI
from langchain_openai import ChatOpenAI

class NachrichtenAnalyse(BaseModel):
    stimmung: str = Field(description="Die Stimmung der Nachricht: positiv, neutral oder negativ")
    hauptthema: str = Field(description="Das Hauptthema der Nachricht")
    dringlichkeit: int = Field(description="Die Dringlichkeit auf einer Skala von 1 (niedrig) bis 5 (hoch)")
    personen: List[str] = Field(description="Liste der in der Nachricht erwähnten Personen")
    
    @validator('stimmung')
    def validate_stimmung(cls, v):
        allowed = ["positiv", "neutral", "negativ"]
        if v.lower() not in allowed:
            raise ValueError(f"Stimmung muss eine der folgenden sein: {', '.join(allowed)}")
        return v.lower()
    
    @validator('dringlichkeit')
    def validate_dringlichkeit(cls, v):
        if not 1 <= v <= 5:
            raise ValueError("Dringlichkeit muss zwischen 1 und 5 liegen")
        return v

# Beispielanwendung
llm = ChatOpenAI(model_name="gpt-3.5-turbo")
nachricht = """Hallo Team, ich bin sehr besorgt über die Verzögerung beim Projekt. 
Peter und Sarah haben noch nicht ihre Berichte eingereicht, und die Deadline ist morgen. 
Bitte kümmert euch dringend darum!"""

analyse = PydanticAI(llm=llm).run(NachrichtenAnalyse, nachricht)
print(f"Stimmung: {analyse.stimmung}")
print(f"Hauptthema: {analyse.hauptthema}")
print(f"Dringlichkeit: {analyse.dringlichkeit}/5")
print(f"Erwähnte Personen: {', '.join(analyse.personen)}")
----

== Erstellung markierter Anweisungen

=== Was sind markierte Anweisungen?

Markierte Anweisungen (annotated instructions) sind Prompts, die mit zusätzlichen Informationen angereichert werden, um dem KI-Modell zu helfen, genauere und strukturiertere Antworten zu liefern. In PydanticAI werden diese Anweisungen oft durch die Metadaten in den Pydantic-Modellen definiert.

=== Implementierung

Du kannst markierte Anweisungen erstellen, indem du:

* Detaillierte Feldbeschreibungen verwendest
* Beispiele für erwartete Antworten bereitstellst
* Zusätzliche Kontext- oder Formatierungshinweise gibst

[source,python]
----
from pydantic import BaseModel, Field
from typing import List, Optional
from pydantic_ai import PydanticAI

class Filmkritik(BaseModel):
    titel: str = Field(description="Der vollständige Titel des Films")
    regisseur: str = Field(description="Name des Regisseurs")
    erscheinungsjahr: int = Field(description="Jahr der Veröffentlichung")
    bewertung: float = Field(
        description="Bewertung auf einer Skala von 1 bis 10",
        ge=1.0,  # Mindestens 1.0
        le=10.0  # Höchstens 10.0
    )
    genre: List[str] = Field(description="Liste der Genres, zu denen der Film gehört")
    zusammenfassung: str = Field(
        description="Kurze Zusammenfassung des Films ohne Spoiler (max. 100 Wörter)"
    )
    staerken: List[str] = Field(description="Die Stärken des Films")
    schwaechen: Optional[List[str]] = Field(
        description="Die Schwächen des Films, falls vorhanden",
        default=None
    )

# Verwende das Modell mit zusätzlichen Anweisungen
prompt = """
    Bitte schreibe eine Kritik für den Film 'Inception' von Christopher Nolan.
    Gehe dabei auf die Handlung, die schauspielerische Leistung und die visuellen Effekte ein.
"""

llm = ChatOpenAI(model_name="gpt-3.5-turbo")
kritik = PydanticAI(llm=llm).run(Filmkritik, prompt)
----

== Einführung in Prompt-Templates

=== Was sind Prompt-Templates?

Prompt-Templates sind wiederverwendbare Vorlagen für Anfragen an KI-Modelle. Sie ermöglichen es, dynamische Inhalte in vordefinierte Strukturen einzufügen, was die Konsistenz und Qualität der Antworten verbessert.

=== Erstellung von Templates

In PydanticAI können wir Templates mit LangChain oder direkt mit String-Formatierung erstellen:

[source,python]
----
from langchain.prompts import PromptTemplate
from pydantic import BaseModel, Field
from pydantic_ai import PydanticAI
from langchain_openai import ChatOpenAI

# Definiere ein Pydantic-Modell
class Zusammenfassung(BaseModel):
    hauptpunkte: list[str] = Field(description="Die wichtigsten Punkte des Textes")
    schlussfolgerung: str = Field(description="Die Hauptschlussfolgerung des Textes")
    zielgruppe: str = Field(description="Die Zielgruppe, für die der Text geschrieben wurde")

# Erstelle ein Prompt-Template
template = PromptTemplate(
    input_variables=["text"],
    template="""Bitte analysiere den folgenden Text und erstelle eine strukturierte Zusammenfassung:

{text}

Deine Analyse sollte die Hauptpunkte, die Schlussfolgerung und die vermutliche Zielgruppe enthalten."""
)

# Verwende das Template mit einem Beispieltext
text = """Künstliche Intelligenz revolutioniert die Art und Weise, wie wir arbeiten und leben. 
Von der Automatisierung repetitiver Aufgaben bis hin zur Unterstützung bei komplexen Entscheidungen 
bietet KI zahlreiche Vorteile für Unternehmen und Einzelpersonen. Allerdings müssen wir auch die 
ethischen Implikationen und potentiellen Risiken berücksichtigen. Eine verantwortungsvolle 
Entwicklung und Nutzung von KI-Technologien ist daher unerlässlich für eine positive Zukunft."""

prompt = template.format(text=text)
llm = ChatOpenAI(model_name="gpt-3.5-turbo")
zusammenfassung = PydanticAI(llm=llm).run(Zusammenfassung, prompt)

print("Hauptpunkte:")
for punkt in zusammenfassung.hauptpunkte:
    print(f"- {punkt}")
print(f"\nSchlussfolgerung: {zusammenfassung.schlussfolgerung}")
print(f"Zielgruppe: {zusammenfassung.zielgruppe}")
----

    print(f"- {argument}")

== Vorbereitung eines Chat-Templates

=== Chat-Templates vs. einfache Templates

Chat-Templates sind speziell für die Arbeit mit Chat-Modellen konzipiert und berücksichtigen die Rollen (System, Benutzer, Assistent) in der Konversation. Im Gegensatz zu einfachen Templates ermöglichen sie eine natürlichere Interaktion mit dem Modell.

=== Implementierung von Chat-Templates

[source,python]
----
from langchain.prompts import ChatPromptTemplate, SystemMessagePromptTemplate, HumanMessagePromptTemplate
from pydantic import BaseModel, Field
from typing import List
from pydantic_ai import PydanticAI
from langchain_openai import ChatOpenAI

# Definiere ein Pydantic-Modell
class Buchempfehlung(BaseModel):
    titel: str = Field(description="Der vollständige Titel des Buches")
    autor: str = Field(description="Name des Autors/der Autorin")
    genre: str = Field(description="Das Genre des Buches")
    zusammenfassung: str = Field(description="Kurze Zusammenfassung des Buchinhalts")
    zielgruppe: str = Field(description="Für wen ist das Buch geeignet")
    seitenzahl: int = Field(description="Ungefähre Anzahl der Seiten")

# Erstelle ein Chat-Template
system_template = """Du bist ein erfahrener Literaturexperte, der personalisierte Buchempfehlungen gibt.
Deine Aufgabe ist es, basierend auf den Interessen und Vorlieben des Benutzers ein passendes Buch zu empfehlen.
"""

human_template = """Ich suche nach einem neuen Buch zum Lesen. Ich mag {genre} und habe {vorherige_buecher} gelesen und gemocht.
Ich suche nach etwas {stimmung} mit {thema} als Thema. Kannst du mir ein Buch empfehlen?"""

system_message_prompt = SystemMessagePromptTemplate.from_template(system_template)
human_message_prompt = HumanMessagePromptTemplate.from_template(human_template)

chat_prompt = ChatPromptTemplate.from_messages([system_message_prompt, human_message_prompt])

# Verwende das Chat-Template
benutzer_praeferenzen = {
    "genre": "Science-Fiction",
    "vorherige_buecher": "'Dune' von Frank Herbert und 'Der Marsianer' von Andy Weir",
    "stimmung": "nachdenklich und philosophisch",
    "thema": "künstliche Intelligenz und Bewusstsein"
}

prompt = chat_prompt.format_messages(**benutzer_praeferenzen)
llm = ChatOpenAI(model_name="gpt-3.5-turbo")
empfehlung = PydanticAI(llm=llm).run(Buchempfehlung, prompt)

print(f"Titel: {empfehlung.titel}")
print(f"Autor: {empfehlung.autor}")
print(f"Genre: {empfehlung.genre}")
print(f"Zusammenfassung: {empfehlung.zusammenfassung}")
print(f"Zielgruppe: {empfehlung.zielgruppe}")
print(f"Seitenzahl: {empfehlung.seitenzahl}")
----

==== Übung: Interviewfragen

Erstelle ein Chat-Template für die Generierung von Interviewfragen. Das Template sollte folgende Variablen enthalten:
- Position (z.B. "Software-Entwickler")
- Erfahrungsstufe (z.B. "Junior", "Senior")
- Technische Fähigkeiten
- Soft Skills

Verwende dann PydanticAI, um strukturierte Interviewfragen zu erstellen.

*Lösung:*

[source,python]
----
from langchain.prompts import ChatPromptTemplate, SystemMessagePromptTemplate, HumanMessagePromptTemplate
from pydantic import BaseModel, Field
from typing import List, Dict
from pydantic_ai import PydanticAI
from langchain_openai import ChatOpenAI

class Interviewfragen(BaseModel):
    technische_fragen: List[Dict[str, str]] = Field(
        description="Liste der technischen Fragen mit Frage und erwarteter Antwort"
    )
    soft_skill_fragen: List[Dict[str, str]] = Field(
        description="Liste der Soft-Skill-Fragen mit Frage und erwarteter Antwort"
    )
    situationsfragen: List[Dict[str, str]] = Field(
        description="Liste der situationsbezogenen Fragen mit Frage und erwarteter Antwort"
    )
    abschlussfrage: str = Field(
        description="Eine gute Abschlussfrage, um das Interview zu beenden"
    )

# Erstelle ein Chat-Template
system_template = """Du bist ein erfahrener Personalverantwortlicher, der Interviewfragen für technische Positionen erstellt.
Deine Aufgabe ist es, basierend auf der Position, Erfahrungsstufe und den erforderlichen Fähigkeiten relevante Interviewfragen zu generieren.
"""

human_template = """Ich benötige Interviewfragen für die Position '{position}' auf {erfahrungsstufe}-Level.
Die Person sollte folgende technische Fähigkeiten haben: {technische_faehigkeiten}.
Zudem sind diese Soft Skills wichtig: {soft_skills}.
Bitte erstelle eine strukturierte Liste von Fragen für das Interview."""

system_message_prompt = SystemMessagePromptTemplate.from_template(system_template)

== Verkettung von Runnables

=== Was sind Runnables?

Runnables sind in LangChain Komponenten, die eine einheitliche Schnittstelle für die Verkettung von Operationen bieten. Sie ermöglichen es, komplexe Workflows zu erstellen, indem verschiedene Schritte miteinander verbunden werden.

=== Verkettung mit PydanticAI

PydanticAI kann in Runnable-Ketten integriert werden, um strukturierte Daten aus den Antworten von Sprachmodellen zu extrahieren:

[source,python]
----
from langchain.prompts import ChatPromptTemplate
from langchain.schema.runnable import RunnablePassthrough
from pydantic import BaseModel, Field
from typing import List
from pydantic_ai import PydanticAI
from langchain_openai import ChatOpenAI

# Definiere ein Pydantic-Modell
class Nachrichtenartikel(BaseModel):
    titel: str = Field(description="Der Titel des Artikels")
    zusammenfassung: str = Field(description="Eine kurze Zusammenfassung des Artikels")
    schlagworte: List[str] = Field(description="Relevante Schlagworte für den Artikel")

# Erstelle ein Prompt-Template
template = ChatPromptTemplate.from_template(
    """Schreibe einen kurzen Nachrichtenartikel über das folgende Thema: {thema}.
    Der Artikel sollte informativ und objektiv sein."""
)

# Erstelle das Sprachmodell
llm = ChatOpenAI(model_name="gpt-3.5-turbo")

# Erstelle eine Runnable-Kette
kette = (
    {"thema": RunnablePassthrough()}
    | template
    | llm
    | PydanticAI(Nachrichtenartikel)
)

# Verwende die Kette

print(f"Zusammenfassung: {ergebnis.zusammenfassung}")

    """
)

== Inspektion Ihrer Kette

=== Warum ist Inspektion wichtig?

Die Inspektion von LangChain-Ketten ist wichtig, um zu verstehen, wie Daten durch die verschiedenen Komponenten fließen und wo möglicherweise Probleme auftreten können. Dies hilft bei der Fehlersuche und Optimierung der Ketten.

==== Übung: Fehlersuche

Erstelle eine Kette mit PydanticAI, die absichtlich einen Fehler enthält (z.B. ein Feld mit einem falschen Datentyp), und verwende die Inspektion, um den Fehler zu identifizieren und zu beheben.

*Lösung:*

[source,python]
----
from langchain.prompts import ChatPromptTemplate
from langchain.schema.runnable import RunnablePassthrough
from langchain.callbacks import ConsoleCallbackHandler
from pydantic import BaseModel, Field, validator
from typing import List
from pydantic_ai import PydanticAI
from langchain_openai import ChatOpenAI
import logging

# Konfiguriere Logging für die Fehlersuche
logging.basicConfig(level=logging.INFO)

# Definiere ein Pydantic-Modell mit einem problematischen Feld
class Rezeptanalyse(BaseModel):
    name: str = Field(description="Name des Rezepts")
    zubereitungszeit: int = Field(description="Zubereitungszeit in Minuten")  # Erwartet eine Zahl
    schwierigkeitsgrad: str = Field(description="Schwierigkeitsgrad: einfach, mittel oder schwer")
    zutaten: List[str] = Field(description="Liste der benötigten Zutaten")
    
    # Validator für den Schwierigkeitsgrad
    @validator('schwierigkeitsgrad')
    def validate_schwierigkeitsgrad(cls, v):
        allowed = ["einfach", "mittel", "schwer"]
        if v.lower() not in allowed:
            raise ValueError(f"Schwierigkeitsgrad muss einer der folgenden sein: {', '.join(allowed)}")
        return v.lower()

# Erstelle ein Prompt-Template
template = ChatPromptTemplate.from_template(
    """Analysiere das folgende Rezept: {rezept}.
    Gib den Namen, die Zubereitungszeit, den Schwierigkeitsgrad und die Zutaten an."""
)

# Erstelle das Sprachmodell mit Callbacks für die Inspektion
llm = ChatOpenAI(
    model_name="gpt-3.5-turbo",
    callbacks=[ConsoleCallbackHandler()]
)

# Erstelle eine Runnable-Kette mit Fehlerbehandlung
def handle_error(error):
    print(f"Fehler aufgetreten: {error}")
    print("Versuche, das Problem zu beheben...")
    
    # Analysiere den Fehler
    if "zubereitungszeit" in str(error).lower():
        print("Problem mit dem Feld 'zubereitungszeit' erkannt.")
        print("Mögliche Lösung: Stelle sicher, dass die Zubereitungszeit als Zahl angegeben wird.")
    
    # Weitere Fehleranalysen könnten hier hinzugefügt werden
    
    return {"name": "Fehler bei der Analyse", "zubereitungszeit": 0, "schwierigkeitsgrad": "mittel", "zutaten": []}

kette = (
    {"rezept": RunnablePassthrough()}
    | template
    | llm
    | PydanticAI(Rezeptanalyse)
).with_verbose(True)  # Aktiviere den Verbose-Modus

# Füge Fehlerbehandlung hinzu
kette_mit_fehlerbehandlung = kette.with_fallbacks([handle_error])

# Verwende die Kette mit einem problematischen Rezept
rezept = """Spaghetti Carbonara

Zubereitungszeit: etwa eine halbe Stunde
Schwierigkeitsgrad: mittel

Zutaten:
- 400g Spaghetti
- 200g Pancetta oder Guanciale
- 4 Eier
- 100g Pecorino Romano
- Salz und Pfeffer

Zubereitung: Nudeln kochen, Pancetta anbraten, mit Eiern und Käse vermengen."""

try:
    ergebnis = kette.invoke(rezept)
    print(f"\nName: {ergebnis.name}")
    print(f"Zubereitungszeit: {ergebnis.zubereitungszeit} Minuten")
    print(f"Schwierigkeitsgrad: {ergebnis.schwierigkeitsgrad}")
    print("Zutaten:")
    for zutat in ergebnis.zutaten:
        print(f"- {zutat}")
except Exception as e:
    print(f"Fehler: {e}")
    print("Versuche mit Fehlerbehandlung...")
    ergebnis = kette_mit_fehlerbehandlung.invoke(rezept)
    print(f"\nName: {ergebnis.name}")
    print(f"Zubereitungszeit: {ergebnis.zubereitungszeit} Minuten")
    print(f"Schwierigkeitsgrad: {ergebnis.schwierigkeitsgrad}")
    print("Zutaten:")
    for zutat in ergebnis.zutaten:
        print(f"- {zutat}")

== Erweiterung Ihrer Kette

=== Hinzufügen von benutzerdefinierten Komponenten

LangChain-Ketten können mit benutzerdefinierten Komponenten erweitert werden, um spezifische Anforderungen zu erfüllen. Dies kann durch die Erstellung eigener Runnable-Klassen oder durch die Verwendung von Lambda-Funktionen erfolgen.

=== Implementierung von Erweiterungen

[source,python]
----
from langchain.prompts import ChatPromptTemplate
from langchain.schema.runnable import RunnablePassthrough, RunnableLambda
from pydantic import BaseModel, Field
from typing import List, Dict, Any
from pydantic_ai import PydanticAI
from langchain_openai import ChatOpenAI

# Definiere ein Pydantic-Modell
class Nachrichtenanalyse(BaseModel):
    titel: str = Field(description="Der Titel der Nachricht")
    zusammenfassung: str = Field(description="Eine kurze Zusammenfassung der Nachricht")
    stimmung: str = Field(description="Die Stimmung der Nachricht: positiv, neutral oder negativ")
    themen: List[str] = Field(description="Die wichtigsten Themen der Nachricht")

# Benutzerdefinierte Komponente: Stimmungsanalyse
def stimmungsanalyse_verbessern(ergebnis: Dict[str, Any]) -> Dict[str, Any]:
    """Verbessert die Stimmungsanalyse mit zusätzlichen Informationen."""
    # Extrahiere die ursprüngliche Stimmung
    stimmung = ergebnis["stimmung"].lower()
    
    # Füge zusätzliche Informationen hinzu
    if stimmung == "positiv":
        ergebnis["stimmung_details"] = "Die Nachricht hat einen optimistischen Ton."
    elif stimmung == "negativ":
        ergebnis["stimmung_details"] = "Die Nachricht hat einen pessimistischen Ton."
    else:  # neutral
        ergebnis["stimmung_details"] = "Die Nachricht hat einen ausgewogenen Ton."
    
    return ergebnis

# Benutzerdefinierte Komponente: Themenanalyse
def themen_kategorisieren(ergebnis: Dict[str, Any]) -> Dict[str, Any]:
    """Kategorisiert die Themen in verschiedene Bereiche."""
    # Definiere Kategorien und Schlüsselwörter
    kategorien = {
        "Politik": ["regierung", "politik", "wahl", "partei", "parlament"],
        "Wirtschaft": ["wirtschaft", "finanzen", "markt", "unternehmen", "aktien"],
        "Technologie": ["technologie", "tech", "digital", "software", "hardware", "ki", "internet"],
        "Gesellschaft": ["gesellschaft", "sozial", "bildung", "gesundheit", "kultur"],
        "Umwelt": ["umwelt", "klima", "natur", "nachhaltigkeit", "energie"]
    }
    
    # Initialisiere Kategorien
    ergebnis["themen_kategorien"] = {}
    
    # Kategorisiere die Themen
    for thema in ergebnis["themen"]:
        thema_lower = thema.lower()
        for kategorie, schluesselwoerter in kategorien.items():
            if any(wort in thema_lower for wort in schluesselwoerter):
                if kategorie not in ergebnis["themen_kategorien"]:
                    ergebnis["themen_kategorien"][kategorie] = []
                ergebnis["themen_kategorien"][kategorie].append(thema)
    
    return ergebnis

# Erstelle ein Prompt-Template
template = ChatPromptTemplate.from_template(
    """Analysiere die folgende Nachricht und extrahiere den Titel, eine kurze Zusammenfassung, 
    die Stimmung und die wichtigsten Themen:

    {nachricht}
    """
)

# Erstelle das Sprachmodell
llm = ChatOpenAI(model_name="gpt-3.5-turbo")

# Erstelle eine erweiterte Runnable-Kette
kette = (
    {"nachricht": RunnablePassthrough()}
    | template
    | llm
    | PydanticAI(Nachrichtenanalyse)
    | RunnableLambda(stimmungsanalyse_verbessern)  # Füge die Stimmungsanalyse-Komponente hinzu
    | RunnableLambda(themen_kategorisieren)  # Füge die Themenanalyse-Komponente hinzu
)

# Verwende die erweiterte Kette
nachricht = """Die Europäische Kommission hat heute neue Richtlinien für den Einsatz von 
künstlicher Intelligenz vorgestellt. Die Regelungen sollen sicherstellen, dass KI-Systeme 
transparent, sicher und ethisch sind. Unternehmen begrüßen die Klarheit, während 
Datenschutzexperten vor möglichen Lücken warnen."""

ergebnis = kette.invoke(nachricht)

print(f"Titel: {ergebnis['titel']}")
print(f"Zusammenfassung: {ergebnis['zusammenfassung']}")
print(f"Stimmung: {ergebnis['stimmung']}")
print(f"Stimmungsdetails: {ergebnis['stimmung_details']}")
print("Themen:")
for thema in ergebnis["themen"]:
    print(f"- {thema}")
print("\nThemen nach Kategorien:")
for kategorie, themen in ergebnis["themen_kategorien"].items():
    print(f"{kategorie}:")
    for thema in themen:
        print(f"- {thema}")
----

== Fragen mit Kontext stellen

=== Warum ist Kontext wichtig?

Kontext ist entscheidend für die Qualität der Antworten von KI-Modellen. Durch die Bereitstellung relevanter Informationen können die Modelle präzisere und nützlichere Antworten liefern. In PydanticAI kann Kontext verwendet werden, um strukturierte Daten aus komplexen Szenarien zu extrahieren.

=== Implementierung von Kontext

[source,python]
----
from langchain.prompts import ChatPromptTemplate

from typing import List
from pydantic_ai import PydanticAI
from langchain_openai import ChatOpenAI

# Definiere ein Pydantic-Modell für die Antwort
class Antwort(BaseModel):
    antwort: str = Field(description="Die Antwort auf die Frage")
    quellen: List[str] = Field(description="Die Quellen, die zur Beantwortung der Frage verwendet wurden")
    sicherheit: int = Field(description="Die Sicherheit der Antwort auf einer Skala von 1 bis 10")

# Erstelle ein Prompt-Template mit Kontext
template = ChatPromptTemplate.from_template(
    """Beantworte die folgende Frage basierend auf dem bereitgestellten Kontext:

    Kontext:
    {kontext}

    Frage:
    {frage}

    Gib eine präzise Antwort und liste die Quellen auf, die du zur Beantwortung verwendet hast.
    Gib auch an, wie sicher du dir bei deiner Antwort bist (1-10)."""
)

# Erstelle das Sprachmodell
llm = ChatOpenAI(model_name="gpt-3.5-turbo")

# Erstelle eine Runnable-Kette
def combine_inputs(inputs):
    return {
        "kontext": inputs["kontext"],
        "frage": inputs["frage"]
    }

kette = (
    RunnableLambda(combine_inputs)
    | template
    | llm
    | PydanticAI(Antwort)
)

# Verwende die Kette mit Kontext

Die Hauptvorteile sind:
1. Typsicherheit durch Pydantic-Modelle
2. Einfache Integration mit LangChain und anderen KI-Bibliotheken
3. Robuste Fehlerbehandlung
4. Unterstützung für verschiedene LLM-Anbieter wie OpenAI, Anthropic und Google

    relevante_dokumente = []
    
    # Einfache Schlüsselwortsuche (in der Praxis würde man Embeddings verwenden)
    schluesselbegriffe = frage.lower().split()
    
    for dok_id, inhalt in dokumente.items():
        if any(begriff in inhalt.lower() for begriff in schluesselbegriffe):
            relevante_dokumente.append({"id": dok_id, "inhalt": inhalt})
    
    return relevante_dokumente

# Erstelle ein Prompt-Template mit Kontext
template = ChatPromptTemplate.from_template(
    """Beantworte die folgende Frage basierend auf den bereitgestellten Dokumenten:

    Dokumente:
    {dokumente}

    Frage:
    {frage}

    Gib eine präzise Antwort, liste die relevanten Dokumente auf und gib an, 
    welche Informationen möglicherweise fehlen, um die Frage vollständig zu beantworten."""
)

# Erstelle das Sprachmodell
llm = ChatOpenAI(model_name="gpt-3.5-turbo")

# Funktion zur Vorbereitung der Eingabe
def prepare_input(inputs):
    frage = inputs["frage"]
    relevante_dokumente = dokumente_auswaehlen(frage)
    
    # Formatiere die Dokumente für das Prompt
    dokumente_text = ""
    for dok in relevante_dokumente:
        dokumente_text += f"[{dok['id']}]: {dok['inhalt']}\n"
    
    return {
        "dokumente": dokumente_text,
        "frage": frage
    }

# Erstelle eine Runnable-Kette
kette = (
    RunnableLambda(prepare_input)
    | template
    | llm
    | PydanticAI(DokumentenAntwort)
)

# Verwende die Kette mit einer Frage
frage = "Was sind die Hauptvorteile von PydanticAI und wann wurde es veröffentlicht?"

ergebnis = kette.invoke({"frage": frage})

print(f"Antwort: {ergebnis.antwort}\n")
print("Relevante Dokumente:")
for dok in ergebnis.relevante_dokumente:
    print(f"- {dok}")
print("\nFehlende Informationen:")
for info in ergebnis.fehlende_informationen:
    print(f"- {info}")
